# Chesed Atlas

말씀의 우주를 항해하는 당신을 위한 지도 — 헤세드 플래닛(CHESED PLANET)

성경 인물 248명의 관계도, 이스라엘·유다 왕과 선지자 연대표(성경 찾기 막대, 구절로 시대 찾기), 아브라함·출애굽·바울 전도여행 등 이동 경로 지도를 담은 웹앱입니다.

- 사이트: https://chesedplanet.github.io/chesed-atlas/
- 휴대폰에서는 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.

## 파일
- `index.html` — 페이지 전체 (데이터·화면·기능)
- `manifest.webmanifest`, `sw.js`, `icons/` — 웹앱 설치와 오프라인 지원
- `fonts/` — 마롱둥근고딕 (개인 상업용 라이선스로 구매한 글꼴. 이 사이트에 쓰이는 글자만 담은 표시용 파일이며 재배포 불가)
